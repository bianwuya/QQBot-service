# P10：工具调用框架

## 目标

建立受控 Function Calling / Tool Calling 基础设施。

本阶段只实现“工具协议 + 权限 + 参数验证 + 审计 + 少量低风险工具”。

**不开放任意 Shell，不开放任意文件系统，不做指定应用控制。**

---

## 1. 核心架构

```text
LLM
 │
 │ tool_request
 ↓
Tool Broker
 ├─ 工具存在性
 ├─ 用户权限
 ├─ scope 权限
 ├─ 参数 Schema
 ├─ 风险级别
 ├─ 调用频率
 └─ 是否需要确认
 ↓
Executor
 ↓
Tool Result
 ↓
LLM
```

模型不能直接调用 Python 函数。

---

## 2. 工具等级

定义：

```text
L0 = 只读查询
L1 = Bot 内部低风险修改
L2 = 指定应用操作
L3 = 系统级能力
```

P10 只开放 L0 和极少量 L1。

L2 仅定义接口，不实现应用控制。

L3 不实现。

---

## 3. 第一批工具

建议：

```text
get_time
get_bot_status
get_model_list
search_memory
search_knowledge
get_recent_files
```

如实现 L1，可加入：

```text
reset_own_context
switch_own_role
```

具体需符合现有权限语义。

---

## 4. 工具注册表

建议：

```text
tools/
├── registry.py
├── broker.py
├── schemas.py
├── audit.py
└── builtin/
```

每个工具至少声明：

```text
name
description
risk
permissions
parameters_schema
handler
timeout
```

---

## 5. 权限

继续以 `config.admins` 为管理员唯一来源。

普通用户默认只能 L0。

管理员可使用允许的 L1。

不能因为群主/群管理员身份自动获得工具权限。

---

## 6. 参数验证

所有参数必须在 Tool Broker 中验证。

禁止：
- 模型直接传任意路径；
- 模型直接传任意 URL 并绕过 safe_net；
- 任意命令行字符串；
- 动态 import；
- eval/exec。

---

## 7. 审计

新增 `tool_audit`。

记录：

```text
time
scope
actor_hash / 安全标识
tool_name
risk
result
duration
error_code
```

禁止记录：
- 消息正文；
- Token；
- 密码；
- 敏感参数明文。

---

## 8. 调用循环限制

单条用户消息：

```text
最多 3 次工具调用
```

防止模型无限循环。

同一工具失败后不得无限重试。

---

## 9. 测试

至少覆盖：

1. 工具注册；
2. 未知工具拒绝；
3. 参数错误拒绝；
4. 普通用户不能调用管理员工具；
5. 群管理员不提权；
6. config.admins 生效；
7. 调用次数上限；
8. 超时；
9. 审计写入；
10. 审计不记录敏感正文；
11. 工具异常不会打崩 Bot；
12. 模型不能直接调用 handler。

---

## 10. 不允许做的事

- 不执行 Shell。
- 不启动/停止外部应用。
- 不允许任意路径。
- 不允许任意 PowerShell。
- 不实现 L3。
- 不改变 P11 的应用白名单设计。

---

## 11. 完成标准

- Tool Broker 可用；
- L0 工具可真实执行；
- 权限与 Schema 校验完整；
- 有审计；
- 有调用次数与超时限制；
- 现有无工具模型路径仍可正常工作；
- 原测试 + 新测试全部通过。
