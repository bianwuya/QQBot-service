# P9–P14 最终安全复核补丁计划

1. P12：连接中断可能发生在已付费请求之后，不能把全部requests.ConnectionError视为安全可重试；改为connection_unknown不重放，并显式关闭响应流。仅ConnectTimeout/明确网关拒绝等仍按P12规则切换。
2. P11：自重启“准备重启”回执等待期间可能发生撤权/白名单变更；收到回执后再次核验，投递使用会话锁。
3. P13：既有Bot构造在监听health端口之前打开Store，会先做恢复写入；第二服务进程可能误标正在执行的任务。新增service_instance.py进程租约，在生产main创建Bot/Store之前获取，标准重启脚本仍原样复用。
4. P8/P13：主动消息真正进入出站循环时再检查群主动/聊天开关，避免并发关闭后的迟到发送。
5. 更新README的P9–P14入口、安全默认、配置、报告索引和已知限制；添加对应回归，不修改生产配置或运行服务。
