## 背景与决策

线上小杂鱼被评价为“人机、不像网传雌小鬼”。诊断：① 9/23 的“声线重构”为避免“傻白甜”把拖腔、语气词一并禁掉，并在输出指令里写死“先答对再带口吻”，成了“助手加辩手”；② `corpus.json` 无出处，词域集中在“前提/证据/破绽”，导致句式复读。

操作者的六项决策：

1. ♡ **启用**（仅嘲讽/得意句；安慰与回应示爱时禁止；群内最近 3 条回复已用过则去掉）；
2. 称呼：“前辈”（反讽敬称）要用，“大叔/叔叔”不启用（按“前辈要用”理解，待确认）；
3. 嘲讽强度默认**温和**（三档可由指定管理员调整）；
4. **不做**用户退出嘲讽模式；
5. 同意少量模型费用做离线对比评测；
6. 机制层（拆条、打字间隔、戳一戳、复读去重）与声线一起改。

## 实现内容

**声线（数据层）**
- `corpus.json`：76+3 句，全部带出处（`provenance`：等级、出处、链接、强度）；A 级中文原句、B 级官方台词（提示词里说明名字映射）、B-ja 日文台本译文、legacy 前任自写的功能句（待确认）。新增 3 句真实的长瀞章节标题，使“前辈”有素材。
- `card.json`：内核“高攻低防、嘴硬心软”；求助“嘴上嫌弃、手上帮忙”；情绪“否认式关心”且不拿难过开玩笑；被夸得意收下；黄腔/家人梗一句打发；禁括号动作、禁猜对方身份、禁提做不到的邀约；回复 40 字内；`ooc` 的 `sweet_tone` 只留讨好型，`care_tone` 禁安慰时的 ♡。
- `prompt.md`：14 区块合并为 9 个，新增“怎么说话”与“嘲讽强度”。

**嘲讽强度**：`card.json` 的 `tease` 定义温和/标准/辛辣三档（默认温和），档位规则进入提示词，并在 `provenance.strength` 的基础上优先抽取不高于当前档位的参考句。管理员命令 `/嘲讽 温和|标准|辛辣|默认`（群内只改本群，私聊改全局默认），`/人格状态` 会显示当前档位。

**机制层**
- 拆条：只在句末标点处拆，每段 ≥6 字、后一段不以“可是/但是/不过…”开头，默认拆条概率由 0.55 降到 0.2；第二段前加 1–3 秒打字间隔（`delay`，发送循环里的 `typing_pause`）。
- 戳一戳：仅在 chat/greeting/insult/flirt 且回复 ≤48 字时才可能触发。
- 复读：`phrase_repeat`（最近 4 条里 ≥2 条含同一 ≥5 字短语则改写一次）；`style.fatigue`（可配置）：最近几条已用过“杂鱼/本小姐/句末~/嘻嘻”就提示这条别用，开头重复则提示换开头，最近没用“前辈”且场合轻松时给出建议。
- 家人梗触发词并入 `insult` 意图；`LLM.chat` 增加可选、白名单、限幅的采样参数（仅评测工具使用，生产调用路径不变）。
- 新增评测工具 `tools/persona_ab_eval.py`：用真实 `Bot` 流水线跑合成群聊场景，临时库、QQ 被 mock，只调模型网关。

## 离线评测（合成场景，同一模型）

方法：30 个合成群聊场景（斗嘴、问候、逗 bot、夸奖/示爱、家人梗、色图关键词、求助、情绪、纠错、记忆、身份），每场景 1 次，经真实 `Bot.group_role_answer`；旧版为快照提交导出的代码。指标为正则统计，非人工评分；每种 n=30，差异在几个百分点内不具统计意义。

| 指标（占回复 %） | 旧版（快照） | 新版（最终） |
|---|---|---|
| “杂鱼”称呼 | 17 | 30 |
| 拖腔 `~ ——` | 0 | 53 |
| ♡ | 0 | 7 |
| 语气词（诶/哈？/呐/嘛/嘻嘻…） | 3 | 47 |
| 笑声（嘻嘻/哈哈…） | 0 | 0 |
| “才不是…/勉为其难” | 0 | 3 |
| “前辈”反讽称呼 | 17 | 20 |
| 助手/长辈/辩论腔 | 0 | 0 |
| 旧口癖（倒是/别到时候/理论…实战） | 7 | 13 |
| 字数中位 | 32 | 27 |
| 兜底台词次数 | 0 | 0 |
| 每场景模型调用次数 | 1.0 | 1.03 |

**结论**：① 旧版满屏“我手头有个题目，你答对了算你赢”式的出题挑战；新版是斗嘴、嫌弃着帮忙、嘴硬式关心；② 拖腔由 0% 到 53%，与真实语料（约 53%）相当；③ 杂鱼 30%、♡ 7%，处于温和档的预期；④ 助手腔、名字泄漏、兜底均为 0；⑤ “倒是/倒挺”仍偶尔出现（13%），可再加一个疲劳项。

## 已知限制

- 评测是合成场景 + 正则指标 + 我读回复的主观判断，不是人工评分；真实群聊里的效果仍要灰度观察。
- 真实素材偏少，被反击/喷子训诫/拒绝等类别仍靠 legacy 句或提示词规则；legacy 句待操作者确认。
- “前辈”依赖建议型提示，比例约 20–50%，随模型而异。
- 未做：用户退出嘲讽模式（按决策）、采样参数接入生产、按意群拆条之外的自然化（如表情包）。
- `glm-5.3-flash` 在当前调用参数下返回空正文，不可用；`gpt-6-luna` 有一次乱码字。
