# P8 最小改造计划

本轮操作者明确要求推进 P8，按此最新指令开展 P8；P7.1 仍在原分支，未替操作者宣称人工验收、未合并 main。保留既有未提交改动，使用独立 P8 工作分支，不读取 P9～P14。

## 文件与职责

- 新增 social_engine.py：群开关、规则预筛、有限内存窗口、持久化预算与无人回应计数、角色策略和安全纯文本输出。
- 新增 social_scheduler.py：定时节流，调用应用回调；不拼 prompt、不直接写 OneBot。
- 修改 app.py：入口旁路观察普通群聊、管理员 /主动 命令、单 worker 空闲时执行主动任务；复用已有 outbox/receipt 投递。不增加并发 worker。
- 修改 protocol.py：注册管理员命令。
- 修改两张角色卡：补充数据驱动的主动概率/意愿策略，social_behavior 继续作为语气与社交规则源。
- 新增 tests/test_social*.py：规则边界、跨群隔离、权限、输出安全、投递与被动回归。
- 修改 README.md，新增 docs/mcp-p8-proactive-chat.md：使用说明和阶段报告。

## 必须保持

默认关闭；config.admins 唯一授权；群主/管理员不提权；不触碰 persona.py、模型容灾、下载防护与加密。私聊历史不读，群窗口仅驻内存有条数/字符/时间上限，不落额外完整聊天日志。主动任务不增加关系/长期记忆轮数。模型不获得工具，生成结果不重新送入命令/下载入口。未知投递不自动重发，模型调用前保守预占预算，失败不退以防刷调用。测试使用临时库和 mock，禁止自动启用真实群或发真实 QQ 消息。
